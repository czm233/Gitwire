# 任务

对上面**每个** issue 做情报分析（Gitwire 只分析、不参与）：

1. **难度**：简单 / 中等 / 困难
   - 简单：文档、配置、小修小补、范围明确的一行级修复
   - 中等：单模块内的功能或修复，需要读懂一处逻辑
   - 困难：跨模块、架构级、需要设计决策、信息不足无法定位
2. **一句话结论**（≤40 字）：这个 issue 是什么、值不值得做
3. **问题分析**：问题本质、大概率涉及哪里（不确定标「未核实」）
4. **方案评估**：可能的修法方向 + 工作量级（小时级/天级/周级）+ 风险点
