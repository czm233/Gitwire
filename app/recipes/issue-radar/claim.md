# 口认领检测（issue-radar·claim）

- 目标仓库：{{REPO}}
- 检测时间：{{DATE}}

下面是若干无人认领 issue 的**新增评论**。判断其中是否有人在声称自己正在（或准备）实现该 issue：

- **算认领**：出自潜在贡献者本人，如 "I'd like to work on this" / "I'm working on a PR" / "我来实现" / "给我做" ——认领人 = 说这话的评论作者
- **也算认领**：贡献者提出修复方案 + 维护者/官方明确点名批准他去做（如 "approved, go ahead" / "assigned to you" / "请你来修"）——认领人 = 提出方案的贡献者本人（即使他没明说"我来修"）
- **不算认领**：issue 作者自己补充信息、维护者泛泛引导（"PR welcome" / "anyone want to try?"）、单纯讨论 / 提问 / +1 / 报错跟进
- 拿不准就不算
