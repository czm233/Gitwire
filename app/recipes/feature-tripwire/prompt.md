# 任务

对照变更材料，逐条维护哨兵清单：

1. **已有哨兵**：判断本次变更是否影响其判决——出现新证据（支持/推翻）就更新「当前判定」与「依据」，判定方向发生变化即为**翻转**
2. **新哨兵**：材料中出现的值得长期追踪的问题（正在迁移的模块、酝酿中的破坏性变更、安全问题、路线图转折点），追加进清单
3. 与本次变更无关的哨兵原样保留（人工内容必须保留）

# 输出契约（违反即作废重来）

1. 输出完整更新后的清单（是完整文件，不是片段）：

```
<<<FILE:tripwires.md>>>
（完整 markdown：每条哨兵含 编号/追踪目标/当前判定[关注|无异常|已翻转|已解除]/依据[文件或 sha]/更新日期）
```

2. **仅当**某哨兵判定翻转或出现高价值新哨兵时，各输出一行警报（没有就不输出任何警报行）：

```
<<<ALERT:tripwire|哨兵标题|一句话说明翻转内容与新判定>>>
```

3. 最后一行摘要：

```
<<<META:summary>>>一句话说明本次哨兵巡检结论（≤60字）
```

- 中文写作，BLUF；不确定的判定标「未核实」；mermaid 围栏必须配对
