## 项目现状速览

**CC-Balancer 是一个纯前端「额度规划实验室」单页应用**：帮 Coding Plan（5 小时滚动额度窗口）用户模拟自己的工作日，调整首次触发时间以查看各窗口压力与预计空窗，最后生成一份 Prompt 交给用户自己的 AI 去配置定时调用（内容固定 `say OK`）。应用本身不连账号、不发 API 请求，设置仅存 localStorage（README.md:23）。

- **技术形态**：TypeScript + React 19 + Vite 7 + Tailwind v4，运行时依赖仅 react/react-dom，无后端无数据库，部署于 GitHub Pages。
- **体量**：核心源码 7 个文件共 845 行；构建产物 dist JS 213 KB（gzip 68.8 KB）/ CSS 19 KB（本轮实测 `pnpm build`）。
- **质量**：本轮实测 `node tests/planner.test.mjs`（约 60 组断言，覆盖解析基线/守恒/搜索最优性/窗口压力/避用区间）、`pnpm lint`、`pnpm build` **全部通过**。
